# 0.1.0 로컬 시험판

2026-11-02. Windows x64, 설치형·무설치형 EXE.

현재 PC에서는 NSIS 설치·단일 무설치 포장 파일의 실행이 접근 거부로 차단되었습니다. 실제 실행·3D·KMZ 저장을 통과한 `win-unpacked/WTG KMZ Generator.exe` 또는 전체 폴더 ZIP을 우선 사용하세요. ZIP을 전달하면 전체 압축을 푼 후 EXE를 실행합니다. Node.js·Python은 필요하지 않습니다.

입력 검증, 3D 미리보기, 개략 E-175 형상, 방향·높이·로터 자세, KML·DAE·KMZ 생성, 로컬 저장을 구현했습니다. 생성·저장은 인터넷과 개발 도구 없이 사용할 수 있습니다.

이 버전은 미서명이며 제조사 상세 형상은 추정값을 포함합니다. 축 경사·코닝은 0°입니다. 다른 PC·Google Earth 표시·정식 성능 인수와 서명은 추가 검증이 필요합니다. `사용안내.md`, `PRESET.md`, `검증결과.md`를 함께 읽어 주세요.

공개 업로드·자동 업데이트·프로그램 연결 변경·사용자 파일 삭제는 수행하지 않습니다.
