# 풍력발전기 KMZ 생성기 사용 안내

## 실행과 파일 전달

**현재 PC에서 확인한 실행 방법:** `program/win-unpacked/WTG KMZ Generator.exe` 실행. 다른 사람에게는 `WTG-KMZ-Generator-Folder-0.1.0-x64.zip` 전체를 전달하고 압축 해제 후 EXE를 실행하도록 안내하세요. 아래의 단일 무설치·설치형도 생성했지만 이번 PC에서는 NSIS 포장 파일 실행이 Windows 접근 거부로 차단되어 검증하지 못했습니다. 폴더형 프로그램은 실제 실행·3D·KMZ 저장 시험이 통과했습니다.

- `WTG-KMZ-Generator-Portable-0.1.0-x64.exe`: 설치 없이 실행하는 파일입니다. 이 EXE 하나를 전달하면 됩니다. 실행 시 임시 폴더와 사용자 앱 데이터가 사용될 수 있습니다.
- `WTG-KMZ-Generator-Setup-0.1.0-x64.exe`: 사용자 계정에 설치하는 전체 설치 파일입니다.
- `win-unpacked` 폴더의 EXE만 따로 떼어 전달하지 마세요.
- Node.js·Python·npm 설치는 필요하지 않습니다. KMZ 생성에는 Google Earth나 인터넷 연결이 필요하지 않습니다.

이번 파일은 미서명 로컬 시험판입니다. 파일을 전달할 때 버전과 SHA256SUMS.txt를 함께 제공하세요. 조직에서 실행이 차단되면 조직의 정상적인 프로그램 검토 절차를 따르세요.

## 입력 의미

| 항목 | 입력 방법 |
|---|---|
| 위도·경도 | WGS84 십진도, 위도 -90~90 / 경도 -180~180 |
| 허브 높이 | 설치 기준면에서 허브 중심까지, 5~500m |
| 로터 직경 | 최종 날개 끝 회전 궤적의 직경, 10~350m |
| 주풍향 | 바람이 불어오는 진북 기준 방향. 북 0 / 동 90 / 남 180 / 서 270, 360은 0 |
| 설치고 보정 | Google Earth 기준면에 더하는 수직 높이. 양수는 위쪽, -1,000~10,000m |
| 정지 로터 자세 | 로터 정면에서 한 기준 날개가 위를 향하면 0°, 시계방향 증가 |
| 고도 모드 | 기본은 relativeToGround. absolute는 기준면 표고와 수직 기준을 추가 입력 |

5~500m와 10~350m 등의 범위는 이 시험판의 수치·표시 지원 정책입니다. 모든 양수 치수를 허용하는 원문보다 범위가 제한되어 있습니다. 제한을 넘는 제원이 필요하면 검증 범위를 넓힌 새 버전이 필요합니다.

이름은 1~80자입니다. 파일명에 쓸 수 없는 문자는 안전하게 바꾸며, 화면·KML에는 원래 이름을 텍스트로 보존합니다. 로터 직경 175m가 아니면 사용자 변형 모델로 표시합니다.

## 생성과 저장

1. 샘플 좌표를 실제 위치로 변경합니다.
2. 제원 입력 후 **미리보기 생성 / 적용**을 누릅니다.
3. 드래그로 회전, 휠로 확대, 우클릭으로 이동합니다. ‘북쪽에서’·‘동쪽에서’는 지리적 카메라 시점입니다.
4. **KMZ 파일 저장**을 누르고 원하는 폴더를 선택합니다. 취소해도 입력과 생성 결과가 유지됩니다.
5. 입력을 바꾸면 이전 모델임을 표시하고 저장을 잠급니다. 다시 생성한 뒤 저장합니다.
6. 날개 궤적이 기준면 아래로 내려가면 경고를 읽고 확인해야 저장할 수 있습니다.

형상 생성이 실패하면 입력을 확인해 재시도하세요. 저장 실패 시 다른 위치를 선택할 수 있습니다. 기존 파일 덮어쓰기는 확인 후 진행하고, 파일을 사용 중인 프로그램이 있으면 닫으세요.

## 높이 해석

H120·D175이면 반경 87.5m, 회전 최고 도달 207.5m, 최저 여유 32.5m입니다. 화면 카드의 값은 설치 기준면 대비입니다. 설치고 +2m이면 지면 대비 허브는 122m입니다.

absolute에서 표고 300m·설치고 +2m이면 타워 밑면의 KML 표고는 302m, 허브 표고는 422m입니다. 수직 기준은 기록용이며 자동 변환하지 않습니다. 입력 표고와 Google Earth의 해수면 기준 차이를 사용자가 검토해야 합니다.

정지 모델의 최상단과 회전 최고 도달은 로터 자세에 따라 다릅니다. 최저 여유는 주변 산지와의 충돌 판정이 아닙니다.

## Google Earth 확인

Google Earth Pro에서 **파일 → 열기**로 KMZ를 선택합니다. 지형을 켜고 고도 과장을 1배로 설정하세요. 정면·측면·사선 외관, 주풍향, 부유·매몰 여부를 확인합니다. 필요하면 설치고를 보정해 다시 생성합니다.

KMZ에는 KML과 DAE가 함께 들어 있어 다른 모델 파일 없이 전달할 수 있습니다. Google Earth는 별도 설치 대상이며 이 앱이 자동 설치하거나 프로그램 연결을 변경하지 않습니다.

## 정확도와 제한

- E-175 계열 외관을 참고한 개략 모델입니다. 세부 나셀·허브·블레이드 단면·타워 치수는 추정값입니다.
- 공식 기종 검증·시공 설계·측량·안전 이격·충돌 검토를 대체하지 않습니다.
- 축 경사와 코닝은 0°인 단순 모드입니다. 공식 상세 기종 모드는 포함하지 않습니다.
- Windows 11 x64가 최초 확인 대상입니다. 다른 PC·보안 정책·GPU·DPI와 Google Earth의 실제 외관은 추가 검증이 필요합니다.
- 좌표·생성 모델을 외부로 전송하지 않습니다. 입력값은 앱 종료 후 자동 복원하지 않습니다. 저장한 KMZ는 사용자가 보관하세요.
